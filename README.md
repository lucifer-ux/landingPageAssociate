# Associate Landing Page

A landing page for **Associate**, an AI workspace built for legal professionals in India.

## Overview

This site presents Associate's product narrative and go-to-market messaging for advocates, in-house counsel, and legal teams.

Key sections include:
- Hero messaging focused on AI for legal workflows
- Problem statement for context fragmentation and verification burden
- "Tried by lawyers" moving logo slider
- "How Associate Works" act-based product walkthrough
- Security and trust section
- Pricing modal with four plan tiers
- Waitlist signup modal

## Tech Stack

- React
- TypeScript
- Vite
- CSS modules via component stylesheets

This project is intended to market Associate as a trustworthy AI assistant for legal work, with emphasis on verified sources, faster drafting, and practical workflows for Indian legal practice.
